# 仅宠物日常模式 — 2026-09-09

按用户要求，启动默认只显示小宠物。对话气泡、计时卡和底部信息栏默认隐藏；双击宠物展开，再次双击或点“收起”隐藏，Esc 也可收起。键盘聚焦宠物后 Enter/空格切换显示。

单击继续提供摸摸动画，不主动展开信息栏；右键仍可主动打开互动菜单。计时完成、恢复状态等信息在展开后显示，不因后台状态刷新自动弹出信息栏。托盘与用户主动发起的退出确认继续工作。

通过保留布局、隐藏绘制避免展开时宠物跳位。隐藏控件设置 inert、aria-hidden，暂停气泡播报；Rust 鼠标命中区只接收可见区域，使透明空白可穿透。计时逻辑、用户设置和宠物位置不变，每次重新启动都恢复仅宠物模式。
