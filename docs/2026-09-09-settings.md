# 设置面板开发记录 — 2026-09-09

根据用户“需要一个点开的设置菜单，配置各种设置”的要求，本轮优先完成设置入口及实际配置能力。此前提醒流程的后续任务继续保留。

## 交付功能

- 桌宠底部“设置”按钮和托盘“设置…”打开同一个普通、可调整大小的窗口；关闭按钮或 Esc 隐藏窗口，再次打开复用。
- 专注 1–180 分钟、短休息 1–60 分钟、长休息 1–120 分钟，长休息间隔 2–12 轮。
- 桌宠大小 80–240、始终置顶、减少动画，以及跟随系统/浅色/深色主题。
- 开机启动开关仅在明确保存且值改变时更新 Windows 启动注册；启动命令保留运行数据目录并正确引用含空格路径。
- 保存、取消、恢复推荐设置、输入校验及保存反馈；外观预览，保存后同步桌宠。
- 当前运行或暂停阶段保持原时长及轮次计划，新参数用于就绪或新阶段。

## 实现与兼容

`src/SettingsPanel.tsx`、配套 CSS、`src/settings.ts` 和 `src/appearance.ts` 提供面板及主题；Rust `settings.rs` 负责校验、本地读写、窗口应用和自动启动。主窗口、托盘、Tauri 配置及权限增加设置入口与独立窗口。

设置使用现有 `settings` 表的 `app_settings` JSON 项，不修改已发布迁移。计时快照新增 `roundsBeforeLongBreak`，旧快照默认四轮。`lib.rs` 在线程启动前读取绝对路径参数 `--runtime-dir`，用于登录启动时保持指定的数据目录。
