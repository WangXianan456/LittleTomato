# v1.1.0 Windows 免安装版发布

本轮承接最新角色素材、互动与屏幕边缘摆放改动，统一 package.json、npm lockfile、Cargo 与 Tauri 配置版本为 1.1.0。README 首页新增固定名称的 Release 直接下载入口，后续版本沿用同一资产名称即可保持链接有效。

## 分发

- 资产：`LittleTomato-windows-x64-portable.zip`，解压运行 `小番茄/little-tomato.exe`。
- ZIP 内含使用说明、README、代码许可证和卡通素材来源说明；附独立 `SHA256SUMS.txt`。
- Windows 10 2004+ / Windows 11 x64，需要 WebView2 Runtime；程序未进行代码签名。
- 免安装不代表用户数据随包移动：设置、计时记录仍保存在本机用户数据目录。
- 此次采用 Release 优化构建的 ZIP 分发。NSIS 工具下载受阻，未发布或验收 NSIS 安装器。

## 检查

- `npm run check`、9 项前端测试、19 项 Rust 测试、Rust 格式检查、Clippy `-D warnings` 通过。
- `npm run tauri build -- --no-bundle` 通过。已检查解压后 EXE 的 FileVersion / ProductVersion 均为 1.1.0，且 SHA-256 与构建产物一致。
- Windows 回归直接运行 ZIP 解压出的 EXE，覆盖界面、计时、设置、拖动、重启及全部十位卡通伙伴的真实点击。
- 首两次测试被编辑器弹出菜单抢走首次双击；测试现在先对桌宠 SetFocus，再执行真实双击，不用键盘切换代替鼠标断言。
