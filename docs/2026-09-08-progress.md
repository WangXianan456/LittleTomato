## 实现

- 实际启动并观察原型，修正叶片遮住气泡文字的问题，窗口改为 300×420，统计文字增加浅色底以适配深色桌面。
- 默认放到主屏工作区右下方，保留 12 个逻辑像素安全边距；按工作区约束、拖动停止后吸附并保存位置；定期检查显示区域。
- 前端上报圆角命中区域，Rust 每 32ms 查询全局鼠标位置并切换鼠标穿透。保持点击与原生拖动期间的命中状态，避免拖动中失去鼠标。
- 角色支持点击/拖动区分；气泡也可拖动。角色命中区采用近似圆角轮廓，叶片/四肢外沿未做逐像素命中。
- Rust 拆分 `database`、`timer`、`windows`、`commands`、`tray`；React 只读取后端快照，不累计计时时长。
- 默认 25 分钟专注、5 分钟短休息、每四轮 15 分钟长休息；结束后等待用户开始下一阶段。支持暂停、继续、提前结束、跳过待开始的休息。
- 单调时间计时；运行中每秒保存检查点，状态转换即时保存。完成记录与快照同一事务写入，写入失败保留原内存状态。异常退出最多损失最近一个正常检查点间隔；进程阻塞超过 3 秒时保守暂停。
- 重启后暂停未完成计时并提示继续，不累计关闭期间的时间。托盘退出先显示保存退出确认。
- 托盘快捷操作与剩余时间提示。前端捕获 IPC 错误并显示温和错误提示。
- 编号 SQL 迁移至 v2；升级前 `VACUUM INTO` 一致备份，迁移事务失败回滚；保留旧版专注统计并合并查询。
- 增加 Node 自带测试（无需新依赖）与 Rust 单元/数据库集成测试；增加 D 盘开发环境脚本。
