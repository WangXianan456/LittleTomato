# 桌面视线与立体拖动 — 2026-09-09

按用户要求增加桌面鼠标跟随、立体晃动和拖动实体感。

- 分离眼白与瞳孔，鼠标在宠物窗口外也能驱动视线。视线方向归一化并限制幅度，支持桌面负坐标输入。
- CSS 透视提供轻微上下/左右转身及面部前景深度；沿用五位角色造型与原有互动。
- 原生拖动开始时提起、伸出手脚、淡化地面阴影，根据窗口横向移动速度摆动；鼠标释放后弹性归位。
- 接收点击的稳定按钮包住独立的立体视觉层，避免变换后的浏览器命中异常；真实原生窗口仍随鼠标移动并继续保存位置。
- 使用现有 Rust 窗口循环读取鼠标，按逻辑坐标向前端发送变化事件；未变化时不发送，隐藏时不发送。坐标只用于本地视觉效果，不持久化。
- 前端弹簧插值直接更新 CSS，静止后停止 requestAnimationFrame；窗口隐藏、减少动画或系统减少动画时归位，不处理动态视线。卸载清理监听和动画帧。
- 去掉遮挡宠物脸部的悬停长提示，保留辅助技术说明和互动面板中的操作说明。

主要文件：`src/petPhysics.ts`、`src/usePetPhysics.ts`、`src/petPhysics.css`、`src/App.tsx`、`src/PetFeatures.tsx`、`src-tauri/src/windows.rs`。
