# 角色美化与伙伴小屋 — 2026-09-09

按用户增加角色和美化的要求，在现有 CSS 绘制基础上增加四位伙伴：蜜桃桃（粉色桃形与双叶）、芽芽（绿色嫩芽）、云朵（浅蓝云冠）、奶油猫（奶油色、猫耳与胡须）。小番茄继续作为默认角色，五位角色各有欢迎语和点击短语。

设置新增“伙伴小屋”，提供卡片预览、名称、描述和明确选中标记，保存后同步到桌面。取消、恢复推荐设置、减少动画、大小预览及主题继续工作。卡片支持键盘按钮操作及辅助技术选中状态。

`characters.ts` 管理角色目录；`PetFeatures.tsx` 与 `characters.css` 统一桌宠、角色卡片和大小预览的绘制。通过 CSS 继续保持离线与轻量，不新增图片下载或运行依赖。设置 JSON 增加 `character` 字段，Rust 枚举约束可用值；旧设置缺失字段时默认小番茄，不需要数据库迁移。切换不影响计时与专注历史。
