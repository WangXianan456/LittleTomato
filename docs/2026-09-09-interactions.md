# 互动与操作体验 — 2026-09-09

根据用户“加入更多的互动效果、优化用户体验”的要求，本轮围绕五位现有角色增加轻量互动，并改善桌宠计时操作。

## 实现

- 点击角色触发摸摸；底部“互动”或角色右键打开动作面板，提供摸摸、打招呼和伸懒腰。五位角色有独立回应，附带开心表情、挥手、伸展及短暂爱心/星光。
- 视线跟随角色区域内的鼠标，离开后归位；专注、休息和完成采用不同表情。交互动效 2.2 秒后清除，500 毫秒冷却，始终只有一组粒子，避免连点无限堆积；卸载时清理定时器。
- 应用或系统减少动画时禁用动作、视线跟随和粒子；保留文字和静态表情反馈。
- 不修改计时状态，不发送声音或通知。错误、恢复确认和完成提醒优先于互动短语，避免遮蔽关键状态。
- 计时卡新增本轮进度条和可访问进度值，专注与休息有不同颜色。
- 桌宠中对运行或暂停阶段点重置先确认；取消保留计时，确认后重置。失败时保留对话框以便重试。托盘原有操作逻辑不在本轮修改范围。
- 对话框隔离背景交互并管理焦点、Tab 和 Esc；互动面板自动聚焦动作并支持 Esc 关闭。拖动取消后抑制误触摸摸，键盘激活不受残留拖动标记影响。
- 设置分类切换后滚动回顶部；Ctrl+S 保存，未修改时不重复写入。

新增 `interactions.ts`、`interactions.css`、`ConfirmDialog.tsx`，更新 `App.tsx` 和 `SettingsPanel.tsx`。不更改持久化结构或增加依赖。
