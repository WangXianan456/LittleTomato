# 2026-09-09 第二轮开发记录

基于 `a46a429`（1.0.0 代码里程碑）。本轮改动尚未提交或发布，版本号保持 1.0.0。

## 已实现

- 接入 Tauri 官方单实例插件，第二次启动退出自身并显示、聚焦已有窗口。计时与数据库初始化仍只在主实例执行。
- 增加 `system_events` 模块，通过窗口 subclass 接收 `WM_WTSSESSION_CHANGE`、`WM_POWERBROADCAST`；注册当前会话通知，窗口销毁时移除注册和释放回调资源。
- 锁屏、控制台/远程会话断开、睡眠时保守保存最近检查点为暂停状态。解锁、重连、唤醒均不自动继续。
- 分别记录会话锁、断开及电源阻塞状态；唤醒不能清除仍存在的锁屏阻塞。阻塞期间前端和托盘均不能启动/继续计时。
- 快照新增可选 `recoveryReason`，兼容旧数据；支持锁屏、睡眠、断开、重启和进程长时间阻塞提示。无需数据库结构迁移。
- 中断写入与原有计时状态变更遵守先持久化再更新内存；系统阻塞时后台会重试保存。中断不会创建完成记录或增加轮数。
- 托盘菜单显示阶段、状态与剩余时间；按状态切换开始/暂停/继续文案，禁用未到下一阶段的操作。仅状态文案变化时更新原生菜单，所有窗口/托盘调用前释放计时锁。
- 增加 `scripts/smoke-windows.ps1`，独立测试数据写入 `D:\Coding\Runtime\LittleTomato-smoke-*`，测试完成仅停止脚本自己创建的进程。
